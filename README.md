# 足迹与远方 · 沉浸式预览

这是《足迹与远方》的 GitHub Pages 静态预览包，提供第 0—5 幕的连续入口与独立章节直达页面。首页从第 0 幕开始；第二幕使用独立构建包，其余章节由 Vue/Vite 工程构建。

- [第二幕：寻根](https://riddlehuang05.github.io/footprints-and-far-away-preview/page2/)
- [第三幕：觉醒](https://riddlehuang05.github.io/footprints-and-far-away-preview/page3.html)
- [第四幕：远方](https://riddlehuang05.github.io/footprints-and-far-away-preview/page4.html)
- [第五幕：回响](https://riddlehuang05.github.io/footprints-and-far-away-preview/page5.html)

## 发布方式

本仓库只保存网页发布文件，源码和章节内容在团队项目的 `main` 分支维护。GitHub Pages 使用 `main` 分支根目录发布。字体、来源记录与许可证随发布包保留；页面资源位于 `assets/`、`fonts/` 和 `page2/`。

## 字体

- `Footprints Display`：Noto Serif CJK SC Light 子集，300 字重。
- `Footprints Literary`：朱雀仿宋 v0.212 子集，400 字重。

字体来源与许可证见 `fonts/` 和 `licenses/`。
